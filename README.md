# 🎲 El Grimorio Errante - Dados y Bandejas

Landing Page estática, de alto impacto visual y optimizada para conversión directa para el micro-emprendimiento de accesorios de rol (TTRPG): dados artesanales de resina con aristas vivas (sharp-edge), bandejas de tiro plegables y el exclusivo **Sobre Sorpresa de Dados**.

---

## 🎨 Identidad Visual y Paleta de Colores

- **Nombre de Marca:** *El Grimorio Errante - Dados y Bandejas*
- **Fondos Principales:** Verde Esmeralda Místico y Azul Petróleo Profundo (`#082a2c`, `#0d4346`) combinados con Carbón Oscuro (`#0a0d0f`) y Obsidiana (`#07090b`).
- **Acentos Metálicos y Bordes:** Oro Antiguo y Bronce Cálido degradado (`#fceda2`, `#d4af37`, `#8b6d1b`).
- **Tipografía:** Google Fonts `Cinzel Decorative` y `Cinzel` (encabezados de fantasía clásica D&D) con `Inter` (lectura limpia y moderna).

## ✨ Secciones y Funcionalidades Incluidas

1. **Header & Navegación:** Logo de D20 en oro antiguo, enlaces rápidos ("Inicio", "Colección", "Sobre Sorpresa", "Contacto") y botón directo a WhatsApp. Menú hamburguesa responsivo para dispositivos móviles.
2. **Hero:** Título *"El Grimorio Errante"*, subtítulo *"Dados y Bandejas"*, lema *"Equipa tus aventuras con accesorios épicos para tus partidas"* y botones de llamado a la acción metálicos dorados.
3. **Propuesta de Valor (3 Columnas con Bordes Dorados):**
   - *Diseños Únicos y Exclusivos*
   - *Lanzamientos de Alta Precisión (D20 Balanceado)*
   - *Envíos Locales y Regionales*
4. **Catálogo Principal:** Tarjetas para *Set de Dados (Resina y Filos Afilados)* y *Bandejas de Tiro Plegables (Madera y Cuero con Bordes Dorados)* con especificaciones, distintivos y botón de encargo directo por WhatsApp.
5. **Spotlight Exclusivo "Sobre Sorpresa de Dados":** Tarjeta destacada con distintivos *"Edición Limitada"* y *"¡Descubre tu suerte!"*, lista de beneficios y botón que pre-llena el pedido específico en WhatsApp.
6. **Pie de Página:** Enlaces directos y texto de cierre místico.

## 🛠️ Control de Versiones con Git y Despliegue

### Inicializar Repositorio y Subir a GitHub
```bash
git init
git add .
git commit -m "feat: lanzamiento landing page El Grimorio Errante"
git branch -M main
git remote add origin https://github.com/TU-USUARIO/el-grimorio-errante.git
git push -u origin main
```

### Despliegue Gratuito Recomendado (Vercel / Netlify)
1. **Vercel:** Inicia sesión con GitHub en [vercel.com](https://vercel.com), selecciona *"Add New Project"*, importa el repositorio y haz clic en *"Deploy"*.
2. **Netlify:** Inicia sesión con GitHub en [netlify.com](https://netlify.com), selecciona *"Add new site > Import an existing project"*, elige el repositorio y despliega sin necesidad de configurar ningún comando de build.
